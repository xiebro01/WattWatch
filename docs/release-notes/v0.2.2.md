WattWatch 0.2.2 发布了。

一个 Windows 托盘小工具：把 2.4G 接收器和蓝牙外设的电量集中显示，默认 **30 分钟才查一次**、每次读写都开关句柄、设备无应答就指数退避——能看见电量，又不会把外设电池耗掉。

## 本次更新

**修复**

- 断开的设备不再长期占位：连续两次读取失败（默认约 1 小时）就判定断开，从主列表隐藏并移入「其他设备」，标注「已断开 · 上次读数 x 前」；设备重新打开后，下一次读取成功会自动回到主列表。
- 窗口有时被创建到副屏并被压成 420×660 的问题：启动时先落到主屏，再按主屏 DPI 居中，多显示器混合缩放也稳定。

**新增**

- 「其他设备」面板：列出能检测到、但还没有电量读取方式的设备（未适配协议 / 已断开），带 VID:PID 和传输方式，方便判断是"没插上"还是"插上了但没协议"。

## 支持设备

| 设备 | 状态 |
| --- | --- |
| 雷蛇 毒蝰 Viper V3 Pro (`1532:00C1`) | 本机验证，读数与 Synapse 一致 |
| VGN V98 Pro (`320F:5088`) | 本机验证 |
| 飞智 八爪鱼 5 (`37D7:2501`) | 本机验证 |
| 索尼 DualSense / Edge (`054C:0CE6` / `0DF2`) | 本机验证（蓝牙，只读） |
| 漫步者 W830NB、华为 FreeBuds Studio 等经典蓝牙耳机 | 读系统缓存，FreeBuds Studio 待验证 |
| 其它蓝牙设备（含 BLE） | 只要 Windows 里能看到电量就自动识别 |

## 下载与运行

- 下载附件 `WattWatch-0.2.2-win-x64.zip`，解压后双击 `WattWatch.exe`，无需安装 .NET。
- 只支持 Windows 10 / 11 64 位。
- 这是未签名的个人小工具，首次运行 Windows 可能提示"已保护你的电脑"，点「更多信息 → 仍要运行」即可。
- 托盘图标：左键打开主界面，右键是菜单；点「关闭」只是收进托盘，真正退出用托盘右键 → 退出。

## 已知限制

- 雷蛇 / 飞智协议需要发一帧查询，不是零写入；本项目只保证把频率压到最低并明确退避。
- 蓝牙耳机是否显示电量，取决于耳机是否通过 HFP 向 Windows 上报。
